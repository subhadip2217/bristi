# For Bristi

A quiet cinematic page for **Bristi** — whose name means rain (বৃষ্টি).

Open `index.html` in a browser, or enable [GitHub Pages](https://pages.github.com/) on this repo (Settings → Pages → Deploy from branch `main` / root).

## What to try

- **Listen** — synthesized rain sound
- **Wipe the glass** — hold and drag the condensation
- **Rain radio** — including the secret station at 104.9
- **Catch the sky** — collect twelve falling words
- **Paper boat** — send a thought across the puddle
- **Wish rain** — type something and watch it fall

Made by a friend.
