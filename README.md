# For Bristi

A quiet cinematic page for **Bristi** — whose name means rain (বৃষ্টি).

## View it

**Option A — GitHub Pages (best for sharing)**

1. Open the repo → **Settings** → **Pages**
2. Under *Source*, choose **Deploy from a branch**
3. Branch: `main` / folder: `/ (root)` → Save
4. After a minute, the site will be live at:

   **https://subhadip2217.github.io/bristi/**

Send her that link.

**Option B — open locally**

Download the repo and open `index.html` in a browser.

## What to try on the page

- **Listen** — synthesized rain sound
- **Wipe the glass** — hold and drag the condensation over her portrait
- **Rain radio** — stations including the secret one at 104.9
- **Catch the sky** — collect twelve falling words into the jar
- **Paper boat** — send a thought across the puddle
- **Wish rain** — type something and watch it fall through the page

Made by a friend.
